# 🎀 Rakhi Surprise Website

A personal Raksha Bandhan webpage for your brother, built with HTML, CSS and JavaScript.

## Folder structure

```text
rakhi-for-brother/
├── index.html
├── style.css
├── script.js
├── README.md
├── images/
│   ├── memory1.jpg
│   ├── memory2.jpg
│   ├── memory3.jpg
│   ├── memory4.jpg
│   ├── memory5.jpg
│   └── memory6.jpg
└── music/
    └── rakhi-song.mp3
```

## Customize

1. Open `script.js`.
2. Change `const brotherName = "Bhai";` to the name/nickname you use.
3. Replace the six images in `images/` with your own photos. Keep the filenames the same, or update `index.html`.
4. Add a local MP3 at `music/rakhi-song.mp3` if you want background music.
5. Edit the story, captions and letter directly in `index.html`.

## Run locally

Open `index.html` in a browser, or use VS Code + Live Server for the best experience.

## Publish with GitHub Pages

1. Create a GitHub repository, e.g. `rakhi-for-brother`.
2. Upload all files and folders.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. GitHub will provide your public website link.
